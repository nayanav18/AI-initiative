Chatbot Conversation
Enable basic conversational interaction instead of triggering analysis for every input.
Agent should distinguish between conversational queries and analysis-related queries.
Agent Refinement
Refine the agent’s intent understanding and response generation.
Analysis should be generated based on the context and user query.
Dynamic Dashboard
Dashboard should be generated based on the user's requirements rather than displaying predefined KPIs.
System should first understand the available data and suggest relevant KPIs and visualizations.
KPIs should be relevant to the user's search/query.
Persona-Based Experience
Persona identification to be incorporated during login.
Dashboard, KPIs, and pipeline should be aligned with the selected persona and relevant business requirements.
Business name should be associated with the data source for easier identification.
Dynamic Visualizations
Provide an option to change chart types dynamically based on user preference.
Save & Share
Provide functionality to save the finalized dashboard.
Enable dashboard sharing with appropriate access permissions, including edit access where required.
Pipeline
Pipeline structure and data visibility to be organized according to persona-specific requirements.
Overall:
Move towards a conversational, persona-driven, and dynamically generated dashboard experience, where the system responds to the user's requirements rather than presenting only predefined analysis.
